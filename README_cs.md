# AxisLock

AxisLock udržuje pohyb myši přesně ve vodorovném nebo svislém směru.

## Použití

1. Spusťe **AxisLock.app**.
2. Pokud macOS požádá o oprávnění, povolte AxisLock v:
   **Nastavení systému → Soukromí a zabezpečení → Zpřístupnění**
3. Podržte zvolenou aktivační klávesu a pohybujte myší.
4. Po uvolnění klávesy se obnoví běžný pohyb myši.

## Nastavení

AxisLock lze nastavit pomocí ikony v horní liště macOS.

Můžete změnit:

- Povolení / Zakázání
- Citlivost myši
- Práh určení osy
- Spouštěcí klávesu
- Jazyk
- Spuštění po přihlášení

## Požadavky

- macOS 13.0 nebo novější
- Oprávnění zpřístupnění

## Instalace

Instalace není potřeba.

Jednoduše přetáhněte **AxisLock.app** do složky **Applications (Aplikace)**.

## Odinstalace

Ukončete AxisLock a přesuňte **AxisLock.app** ze složky Aplikace do Koše.

## Známá chyba

Pokud je AxisLocku odebráno oprávnění **Zpřístupnění** během jeho používání, může v některých případech dojít k zamrznutí systému macOS.

Doporučuji proto AxisLock před odebráním oprávnění nejprve ukončit.
