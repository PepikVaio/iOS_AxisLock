# AxisLock

AxisLock keeps mouse movement precisely aligned horizontally or vertically.

## How to use

1. Launch **AxisLock.app**.
2. If macOS asks for permission, allow AxisLock under:
   **System Settings → Privacy & Security → Accessibility**
3. Hold the selected activation key and move the mouse.
4. Release the key to restore normal mouse movement.

## Settings

AxisLock can be configured using the icon in the macOS menu bar.

You can change:

- Enable / Disable
- Mouse sensitivity
- Axis detection threshold
- Activation key
- Language
- Launch at login

## Requirements

- macOS 13.0 or later
- Accessibility permission

## Installation

No installation is required.

Simply drag **AxisLock.app** to the **Applications** folder.

## Uninstall

Quit AxisLock and move **AxisLock.app** from the Applications folder to the Trash.

## Known issue

If Accessibility permission is removed from AxisLock while it is running, macOS may freeze in some cases.

It is therefore recommended to quit AxisLock before removing its Accessibility permission.
